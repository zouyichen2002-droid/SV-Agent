# 《傍晚》· 翻唱人声主旋律演示

**作词：zouyichen2002-droid**　·　**原曲**（旋律、编曲、原唱）：Suno 根据作者的歌词生成　·
**作者版**：作者用 Synthesizer V（星尘）翻唱、编曲、调教　·　**AI 扒谱**：SV-Agent（本仓库）

这首是作者自己的歌，也是 SV-Agent 第一个成果的演示：**把 Suno 的人声分轨变成 SynthV 里的主旋律（音符 + 歌词）**。

## 里面有什么

| 文件 | 是什么 |
|---|---|
| `傍晚_AI扒谱_r05.svp` | AI 扒出来的主旋律：189 个音、拼音歌词。用 Synthesizer V Studio 2 打开 |
| `傍晚_AI扒谱_r05_对比作者版.svp` | 同上，另带作者版的主唱和「和声1」，单独放（solo）哪条就听哪条 |
| `傍晚_AI扒谱_r05.mid` | 同一份主旋律的 MIDI（带歌词），能拖进任何编曲软件 |
| `傍晚_作者版_04-17.svp` | 作者手工完成的版本（主唱 + 和声1，含调教） |
| `歌词.txt` | 作者的歌词 |
| `分数.json` | AI 版对作者版的打分 |

- **不含音频**：Suno 的分轨和成品音频都没有放。工程里的音频轨指向 `audio/…`，打开时 SynthV 会提示找不到文件 —— 不影响看音符、听星尘唱
- 声库是星尘（MEDIUM5·Stardust），要自己有这个声库才能渲染
- 速度照作者版的 120 BPM；音按绝对时间放、没有吸到网格上（作者版也是这样）

## AI 版做到什么程度

作者对着自己的版本听过：**基本可用，剩下少数几个音手改就行**。

| 看什么 | 结果 |
|---|---|
| 音符（对作者版主唱；起音差 ≤ 50 ms 且音高差 ≤ 50 音分算扒对） | F1 0.542 |
| 音符（1:56–2:14 那段按作者的「和声1」算 —— 见下） | F1 0.681，八度错只剩 1 个 |
| 歌词 | 按作者给的歌词修过：185 个字全部对上 |
| 参照：作者自己 04-12 第一版对 04-17 终稿 | F1 0.875（人自己改一遍也有 12% 的音不一样） |

**1:56–2:14 为什么要单独算**：Suno 在那段上下两个八度一起唱。作者编曲时把主唱放在下八度、上八度做成「和声1」；
AI 版按「两个八度一起唱就取上面那个」取了上八度 —— 和作者的和声1 一样，和主唱差一个八度。哪条当主唱是编曲选择。
