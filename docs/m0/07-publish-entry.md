## 1. 结论先说

```
                    B站                                  网易云
  文件         视频：AAC ≤320kbps，采样率 = 48000 ⚠        MP3 / WAV，≥320kbps，≥44.1kHz，≤200MB
               音频区：WAV / FLAC / MP3 / WMA，≤200M        （我们的 16-bit / 44.1kHz WAV 直接满足）
  歌词 / 字幕   可上传 ASS 字幕，时间区间不能重叠           纯文本或带时间轴的 LRC，必须和唱的 100% 一致
  翻唱         原则上要版权方授权；音频区必须填原作者、原曲名  【原唱信息】里搜不到或显示「不可翻唱」= 版权方不允许
  AI 内容      ⚠ 国家规定：发布时要主动声明，并用平台的标识功能（2025-09-01 起施行）
               平台的具体做法：B站的公告要登录才能看 ——     有「AI 音乐人」身份；平台认定为 AI 作品会下发这个身份
               第 2 步你核对                                ⚠ 你现在是哪种身份、SynthV 的歌怎么认定，只有你的账号看得到
  状态         审核中 → 通过 / 退回（改完可再交）/ 锁定（不能改）  审核中 → 通过 / 被拒（可补材料，每首只能申诉一次）
```

**两处第三方说法和官方原文对不上**，所以这份清单只认官方：B站视频的音频采样率官方要求 **48000**（第三方写 44100）；
文件大小官方是 16G（第三方写 4GB）。

## 2. 国家规定：《人工智能生成合成内容标识办法》

网信办、工信部、公安部、广电总局联合发布，**2025 年 9 月 1 日起施行**。原文：
<https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm>

| 条款 | 原文 | 对我们意味着什么 |
|---|---|---|
| 第三条 | 人工智能生成合成内容标识包括**显式标识**（文字、声音、图形等用户能明显感知的）和**隐式标识**（文件数据里、不易被感知的） | —— |
| **第十条第一款** | *「用户使用网络信息内容传播服务发布生成合成内容的，应当主动声明并使用服务提供者提供的标识功能进行标识。」* | **你发布时要做的事**。发布包的检查清单里必须有这一项，并准备好声明文字（PRD F2） |
| **第十条第二款** | *「任何组织和个人不得恶意删除、篡改、伪造、隐匿本办法规定的生成合成内容标识，不得为他人实施上述恶意行为提供工具或者服务。」* | **约束我们这个工具本身**：做发布包转码时，不能洗掉文件里原有的标识 |
| 第六条 | 平台要核验文件元数据里的隐式标识、提供标识功能、提醒用户声明 | 平台可能会自动识别 |

**实测：SynthV 导出的 WAV 里没有隐式标识。** M0-04 导出的 `m0_04_MixDown.wav` 只有三块数据（`JUNK` · `fmt ` · `data`），
没有任何元数据，全文也搜不到 AIGC、Synthesizer V 之类的字样。所以发布时的合规动作，主要落在**你上传时主动声明**。

**SynthV 唱的人声算不算「AI 合成」**：第三条把 AI 生成合成内容定义为「利用人工智能技术生成、合成的……音频」，
SynthV 2 的 AI 声库**很可能**在这个范围里。**怎么认定由平台和你来判断，这里不下结论。**

| 篇目 | 原文要点 | 对发布包意味着什么 |
|---|---|---|
| 作品上传异常问题解析（2021-12） | **格式仅限 MP3、WAV · 比特率 320 kbps 以上 · 采样率 44.1 kHz 以上 · 200 MB 以内** | 我们的 16-bit / 44.1 kHz WAV（约 1411 kbps）直接满足；一首 4 分钟的立体声约 42 MB |
| 创作者中心 · 作品和身份管理 | 入口：**音乐人中心 → 发布作品 → 发布歌曲** · 歌词：*「可以填入纯文本歌词，也可以将带有时间轴的LRC歌词直接复制进歌词弹框中」* · MV 只能电脑端上传，审核 1 个工作日 · 可自行下架（付费合作、开了赞赏的除外） | **LRC 从 `.svp` 的音符时间生成**，和唱的逐字对齐 |
| 入驻作品发布及填写相关（2022-08） | 作品类型三种：**原创 / 翻唱 / Remix** · 第一次上传单曲要先**新建专辑** · 翻唱在【原唱信息】里搜索，*「如果歌曲显示不可翻唱无法选择，或者搜索不到原唱版本的，可能是版权方不支持翻唱」* | 翻唱的授权状态：**以【原唱信息】能不能选为准**（PRD F3） |
| 作品审核被拒如何自查（2022-05） | ① 账号有风险时：演唱作品交 30 秒**本人露脸清唱**视频，非演唱作品交 30 秒本人出镜**播放工程文件**视频 ② 用了他人伴奏 / 采样 → 选翻唱 / Remix，或交**分轨、工程录屏、干音**加授权 ③ 检测出相似歌曲 → 原创交分轨、工程录屏、干音 ④ 版权方维权会下架翻唱 ⑤ **歌词和演唱内容必须 100% 一致**，非中文歌词要带中文翻译，纯音乐里有一句人声也要上传歌词 ⑥ 每首歌**只能申诉一次** | 发布包可以附一份**原创证明包**：SynthV 导出的**干音**、FL 的分轨、工程文件。「本人清唱」对虚拟歌手的歌怎么算 → 第 2 步 |

## 5. 第 2 步怎么做

**用你自己的账号**，打开两个平台的上传页，照第 3.2、4.2 节的表**逐项看，不提交、不发布**。
看到什么记一句（截图也行），尤其是：**AI 声明在哪、有哪些选项**，以及**网易云你是哪种身份**。

我不会登录你的账号，也不会替你上传或发布。

## 6. 对发布包设计的直接影响（PRD F1–F5）

| 发布包里的东西 | 按什么做 |
|---|---|
| B站视频 | 封面静帧 + 音频 → H.264 / yuv420 / 8bit，关键帧 ≤ 10 秒一个；**音频 AAC ≤ 320 kbps、48 kHz**（从 44.1 kHz 重采样） |
| B站音频区（可选） | WAV 或 FLAC 原样上传（≤ 200M） |
| 网易云音频 | WAV 16-bit / 44.1 kHz 原样上传（≤ 200MB） |
| 歌词 | 网易云：LRC（带时间轴）；B站字幕：ASS，区间不重叠。**都从 `.svp` 的音符时间生成**，保证和唱的一致 |
| AI 声明 | 准备好声明文字，检查清单里写明「上传时用平台的标识功能」；**转码不洗掉原有标识** |
| 翻唱 | 网易云以【原唱信息】能不能选为准；B站要授权。**缺授权标红，不放行** |
| 原创证明包（网易云被要求时） | SynthV 导出的干音 · FL 分轨 · 工程文件 |
| 封面 | 不能用动图；尺寸等第 2 步核对后再定 |
