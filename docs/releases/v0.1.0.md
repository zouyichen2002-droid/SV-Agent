# v0.1.0 · 第一个成果：翻唱人声主旋律

**Suno 人声分轨 → SynthV 主旋律（音符 + 歌词）**。作者在 Suno 上用歌词生成歌、分好轨，SV-Agent 把人声分轨扒成一个新的
Synthesizer V 工程，作者在里面手改剩下的少数几个音。

演示：[demo/傍晚](../../demo/傍晚)（作者版 + AI 版工程，CC BY-NC 4.0）—— 作者听后：基本可用，剩下少数几个音手改。

## 在《傍晚》上

| 看什么 | 结果 |
|---|---|
| 歌词（按作者给的歌词修） | 185 个字全部对上 |
| 音符 F1（对作者版；1:56–2:14 按作者的和声算） | 0.681，八度错只剩 1 个 |
| 音符 F1（对作者版主唱） | 0.542 |
| 参照：作者自己两版之间 | 0.875 |

## 做法

GAME 切音 + Qwen3-ASR 听写（Vocal2Midi）→ 按作者歌词修歌词（按拼音全局对齐，只改字、不动音）→
挑八度（Suno 上下两个八度一起唱的句子整句取上面那个）→ 写成新的 .svp。详见仓库首页 README。

## 不足

- 只测了一首歌，几处分界线是在这首上定的
- 探针代码写死了本机路径，还不是能直接装的工具
- 不含音频；和声识别不做（以后和声由我们自己写）

原曲由 Suno 根据作者的歌词生成；扒谱用到 GAME、Qwen3-ASR、basic-pitch 等模型；作者版由作者手工完成。
