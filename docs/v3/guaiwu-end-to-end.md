## 2. 哪里慢、哪里出了错

**我错的**（都改了，教训记在开发记忆里）：
- v03 有 18 句字压到人物的手：「整块最宽 880」是我以为的，实际按大字居中、伸出了范围 → 改成按外框放进量过的那 45%，换底片后要量
- 和声 r02 边界多带了一个音：检查用的秒数和工具是同一组，等于自己核自己 → 改成按歌词句子另算
- 第 1 句先把字排错了一个音（r04）：拿一条分不出对错的证据定了 → 音和字怎么对，听不出来就先问你
- 「不要加」理解错成书名号 → 多出了一版 v04

**DSH 的**：
- 开 DSH 的后台任务被系统收掉以后，DSH 起不了子程序（0xC0000142）→ 改成 DSH 用自己的隐藏窗口开；插件遇到这个退出码会直说「要重开 DSH」
- 本地模型在内存紧的时候（你开着游戏，可用 0.2–0.5 GB）写出片参数写到输出上限、被截断 → 最后一版是我直接跑的
- 交付消息说错过成片长度、标题的书名号 → 插件现在把成片时长、后台用时分开写；标题不填就默认《歌名》

**只能你做的**（Windows 的系统窗口、账号）：SV 里导出混音、B 站扫码登录、选文件、点投稿。
