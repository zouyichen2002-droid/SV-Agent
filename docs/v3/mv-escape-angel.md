## 1. 做成了什么

- 成片：1920×1080、60 帧、每帧 16 个子帧的运动模糊，3 分 41 秒；声音是你 10-01 导出的 r02 混音
- 总概念：**小天使的人间手账** —— 一句歌词一页（50 页 + 开场 + 结尾），分上学篇 → 上班篇 → 逃跑篇；页眉写篇名、页码（= 第几句）
- 贯穿线索：**光环**（越来越暗，翅膀被剥夺时几乎熄灭，最后自己飞回星空）+ 每次翻页划过的**金色光点**
- 画风：扁平矢量 MG，暖色纸、墨线、快乐体；小天使是我设计的（圆脑袋、刘海、呆毛、圆羽毛翅膀、铃铛裙）；全部用代码画，没用任何图片素材，没碰原 PV
- 歌词：每页一条纸胶带，整句先淡淡显出，唱到哪个字弹哪个字（逐字时间从 r02 工程算，和混音对过）；有几页把字画进画里（黑板、屏幕打字、模糊的黑板）
- 节奏：换页在每句开始唱之前 0.35 秒（平移 / 上翻 / 下翻 / 推近）；底鼓一响小天使一压一弹、画面轻推；副歌推得更明显；心跳停止那一刻闪白；每页慢慢推近
- 封面：你给的星尘立绘（白边贴纸）+ 副歌那一页 + 手账纸标题；B 站首页推荐要 4:3，另排了一张

## 3. 怎么做的

- 引擎：[mexicat/pdoom-video](https://github.com/mexicat/pdoom-video)（MIT）的引擎部分：每一帧都是歌曲时间的函数（没有状态），后台 Chrome 一帧一帧画、ffmpeg 编码；子帧平均做运动模糊；后期有泛光、颗粒、暗角、推镜、闪白
- 数据（`mv/analysis/prepare_song.py`）：逐字时间用歌词视频那套（`worker/lyric_timing.py`）；拍子用找拍子的结果；底鼓 / 军鼓 / 镲的起音和各声部响度从分离出来的伴奏算；混音和伴奏先对齐（相关 0.939，不用平移）
- 画面（`mv/src/scenes/journal.ts` + `angel/`）：`kit.ts` 是画画工具（配色、云、星、心、日历纸、小天使、逐字歌词）；`panels-a/b/c.ts` 是 52 页；`journal.ts` 管换页、镜头、页眉、光点、每页的后期。**代码里没有歌词原文**（歌词从仓库外的 `lyrics.json` 读）
- 出片：`node scripts/render.ts video --song <项目>\MV --fps 60 --samples 16 --shutter 0.3 --crf 16 --preset slow`；只看效果用 `--fps 30 --samples 1`（整首约 6 分钟）；封面用 `stills --query cover=1`

## 4. 遇到的问题，自己怎么解决的

| 问题 | 怎么解决 |
|---|---|
| 第一版小天使太简笔，翅膀像蝙蝠（下沿的尖朝外） | 重画：羽毛改成往外鼓的圆弧、铃铛裙、胖袖子短腿、刘海呆毛、眼睛高光、脚下影子 |
| 夜景页的黑字看不见；字压在画上看不清 | 夜景页自动换浅色字；所有歌词下面加纸胶带 |
| 快乐体的「0」长得像梯形 | 改成直接画红圈 |
| 躺着的小天使整个转 90 度，很怪 | 改成侧头靠在枕头上、被子盖住身体（床、病床、棺木三页） |
| 换页时给新页加的阴影套到了它上面的每一样东西（慢、发糊） | 只在页边画一道渐变阴影 |
| 头大手短，「举手顶住压板」看起来像捂脸 | 手臂举高时自动变长；压板压到头顶 |
| 翻页的运动模糊是一道道分开的重影（子帧间隔约 5.7 px，比 4 px 描边宽） | 子帧 12 → 16、快门 0.5 → 0.3（间隔约 2.6 px）重出 v02；v01 留作备份 |
| B 站首页推荐封面是 4:3，16:9 的封面一裁就切掉标题和星尘 | 另排一张 4:3 的 |

## 5. 下一首可以更快的地方

- 底子、画画工具、换页 / 镜头 / 后期都能直接用；下一首主要是写那首歌的设计手册和每页画面
- 估运动模糊：最快的运动（像素 / 帧）× 快门 ÷ 子帧数要小于最细的线宽；正式出片前从转场里抽一帧放大看
- 渲染时间：1080p60、16 子帧，整首约 75–80 分钟（低优先级，你用电脑也没关系）
- 这次没用 DSH：这种画面代码本地模型写不了；DSH 还是只管翻唱和普通歌词视频
