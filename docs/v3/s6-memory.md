## 2. 做了什么

DSH 没有现成的记忆插件；它自带的 AGENTS.md 只能放一段固定说明，没有来源、范围、停用、删除，所以自己写了一个。

| | 记什么 | 状态 |
|---|---|---|
| **反馈** | 你评价某首某一版的原话（原样）+ 来源（歌、版本、位置、时间）+ Agent 的一句理解（你可以改） | 记下了 / 已删除 |
| **偏好** | 以后要照着做的规矩：范围（这首歌 / 所有歌，默认这首歌）、强度（必须 / 尽量）、处理方式、用过几次 | 待确认 / 生效 / 被覆盖 / 已停用 / 已删除 |
| **历史** | 每首做过的版本、每版的设置（挑没挑八度、语言）、你的评价 | 从版本清单和 `rNN\song.json` 汇总，不另存 |

- **原话必须原样**：插件拿这个会话里你最近的几条消息对一下，对不上就拒绝（不让模型转述）；确认、删除引的话还要是**在那之后说的**
- **处理方式**（PRD §6.1 的字段）：「流程里照做」= 代码里已经照做的规矩（只进清单，不每步给模型看 —— 省上下文）；
  「Agent 照做」= 模型在对话里要记着的（比如不做试听、戏腔以后再做）；「翻唱时自动」= 有动作的（现在只有「挑不挑八度」）
- **翻唱时自动用**：`cover_run` 开跑时看这首（优先）和全局生效的偏好；这次你没说 → 照偏好；这次你说了、和偏好不一样 → 照你这次的（PRD §6.2：当前明确指令优先），偏好不动、提一句。
  用了哪条写进 `说明.md`、偏好里记一次「用过」（R10「生成记录列出实际采用的偏好」）
- **守 §6.5**：你说「好」只记成那一版的评价，不会因此变成风格偏好；偏好只能由你点头生效
- **每一步给模型的一小段**：生效的「Agent 照做」偏好、这首的偏好和最近 3 条反馈、待确认几条，加一句记忆规矩
- **存在哪**：记忆库在工作区外面 `E:\sv-agent-data\memory\`（`全局记忆.json`、`<歌名>\记忆.json`，Agent 的沙箱写不进去）；
  给人看的清单 `E:\sv-agent-data\memory\全局记忆.md` 和每首项目里的 `记忆.md`（每次改动重写；改它不算数，Agent 用 write / edit 碰它直接拒绝）

| 工具（4 个，工具说明也占 16k 上下文，能少就少） | 做什么 |
|---|---|
| `memory_record` | 记一条反馈（原话 + 理解 + 版本 / 位置），或提议一条偏好（先「待确认」） |
| `memory_confirm` | 你对提议表了态以后：生效（你的回答原样存成「确认」）/ 不要 |
| `memory_change` | 「这条不算」→ 删；停用 / 重新生效；改理解 |
| `memory_list` | 列出全局 + 这首的记忆和做过的版本 |
