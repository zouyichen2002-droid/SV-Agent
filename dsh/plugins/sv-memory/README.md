# sv-memory · 创作记忆插件（v3 阶段 6）

记创作者的**反馈**（他评价某首某一版的原话）、**偏好**（以后要照着做的规矩，他点头才生效）、**历史**（每首做过的版本和设置）。规矩照 PRD §6、§6.5、R10。

创作者 10-01 定：
- 反馈**自动记原话**（Agent 看到他在评价就原样存下、告诉他一句；他说「这条不算」就删）
- 偏好 **Agent 提议、他点头才生效**
- 以前说过的规矩和评价**导进来、他过一遍**（他说「全部生效」）

```
 每一步给模型一小段（sv:memory）：生效的「Agent 照做」偏好 · 这首的偏好和最近 3 条反馈 · 待确认几条 · 一句记忆规矩
 工具：memory_record（记反馈 / 提议偏好）· memory_confirm（他表态以后：生效 / 不要）· memory_change（删、停用、重新生效、改理解）· memory_list
 原话必须原样：拿这个会话里他最近的消息对一下，对不上就拒绝；确认 / 删除引的话要在那之后说的
 存：工作区外面 <store>\全局记忆.json、<store>\<歌名>\记忆.json（Agent 的沙箱写不进去）
 看：<store>\全局记忆.md、<项目>\记忆.md（每次改动重写；Agent 用 write / edit 碰它 → 拒绝）
 sv-cover 用：coverActions(store, 项目) 给出生效的「翻唱时自动」偏好（这首优先于全局）；用了就 recordUse 记一次
```

偏好的「处理方式」：`流程里照做`（代码已经照做的规矩，只进清单、不每步给模型看）/ `Agent 照做`（模型在对话里要记着的）/ `翻唱时自动`（有动作，现在只有 `octave_pick`）。

## 怎么挂的

和别的插件一样：只用 Node 自带模块 + 同仓库的 sv-project / sv-artifact，在配置档补丁里用绝对路径挂成全局一行（见 `../../profile-web.cordis.patch.yml`）：
`root`（项目根）、`store`（记忆库，要在工作区外面）、`artifacts`（sv-artifact 的快照库，拿版本历史用）。
要的 DSH 服务：`tools`、`systemPrompt`；用 `session/event` 记他最近的消息（对原话）。
