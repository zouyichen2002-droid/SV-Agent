# sv-video · 歌词视频插件（v3 视频）

在 DSH 的对话里说「做歌词视频」、给图和成品音频 → 后台跑 `sv-bridge/worker/video_run.py` → 项目里新开的 `视频\vNN\` 出 1080p 成片（mp4），
剪映的草稿文件夹里出一份新草稿「SV-Agent_<歌名>_vNN」。

创作者 10-01 定：
- **先做歌词视频**：图 + 逐字变色的歌词字幕 + 轻微推近；时间从 SV 工程来（翻唱出来的 rNN，他改过存盘的就是改过的）
- **只用他给的图**（不生成）
- **剪映草稿 + 一份成片**：草稿放进剪映的草稿文件夹，**只新建**「SV-Agent_<歌名>_vNN」，不碰他已有的草稿
- 测试片段他看过：「剪映能打开，字幕也跟得上」
- 10-01 晚：「接下来尝试一下特效字幕」→ `video_run` 加了 `fx`（字幕样式：平铺、弹跳、发光、浮现、逐字出现、竖排古风），样片见 `docs/v3/s10-video.md` §5
- 10-02：照创作者给的参考（B 站《樱草哀歌》）做了「可爱」（快乐体、白字彩边带光、几行错落 / 斜台阶）；创作者「效果不错，把可爱设成默认样式」→ **`fx` 不填 = 可爱**
- 10-02《怪物》：画面可以给视频（底片，循环铺满）；加了 `side`（字放左 / 右，不填自动）；日语凌厉用佑字肅
- 10-02：创作者「找一个凌厉的版本」→ 照 B 站「【文字PV】KING」做了「凌厉」（毛笔楷书大字砸进来、竖排小字红白相间、红色刀痕、画面压暗；小字原来是宋体，创作者嫌丑 → 也用毛笔楷书）

```
 video_run 工具（模型调）
   ① 校验：成品音频（绝对路径、是音频）；图（文件或文件夹，文件夹里的图按文件名排；最多 30 张）；
      工程（不给 = 没弃用的 rNN 里最近改过的 .svp，吸格线前的备份不算；rNN；或绝对路径）；素材\歌词_要唱的字.txt 在
   ② 定下一版 vNN：视频\ 里的 vNN / 弃用_vNN 和剪映草稿文件夹里的 SV-Agent_<歌名>_vNN 都算，取最大 + 1（号不复用）
   ③ 起一个后台任务（ctx.jobs.start），马上返回 —— 模型跟创作者说一声就结束这一轮
 后台任务
   ④ 起 Worker（渲染只用 CPU、Worker 把自己调成「低于正常」，子程序跟着低；不用让出大模型）；每 2 秒读 日志\视频进度.jsonl：
      「完成 / 失败 / 提醒」给模型看，其余只给界面看
   ⑤ 成功：记项目状态；结果里给成片路径、草稿名、对齐结果、要提醒创作者的
      失败 / 被停：没做完的 vNN 改名「弃用_vNN（没跑完 …）」/「弃用_vNN（停掉了）」，不删
   ⑥ 任务结束 → DSH 唤醒模型 → 它用 present 把成片交给创作者
 拦写：做好的 视频\vNN\（有 说明.md）、剪映的草稿文件夹 —— Agent 用 write / edit 碰 → 拒绝
 上下文：这首做过视频的话，每一步给模型一小段「歌词视频：v02 做好了…；v01 弃用…」
```

**Worker 不进沙箱**（补丁里 `sandbox: false`）：剪映的草稿文件夹在工作区外面，沙箱写不进去。
Worker 是我们自己的固定流程：模型只能给音频、图、工程的路径和标题、署名，插件先校验；Worker 只往这首歌的 `视频\vNN\` 和草稿文件夹里的新草稿写。

技能说明在 `../../skills/sv-video/SKILL.md`。Worker 的几步（检查、拷素材、逐字时间、对齐、成片、剪映草稿、说明）见 `video_run.py` 开头和 `docs/v3/s10-video.md`。

## 怎么挂的

和 sv-cover 一样：只用 Node 自带模块 + 同仓库的 sv-project、sv-cover（读进度的函数），在配置档补丁里用绝对路径挂成全局一行（见 `../../profile-web.cordis.patch.yml`）。
要的 DSH 服务：`tools`、`jobs`、`sandbox`、`sandboxPolicy`、`systemPrompt`。

## 自检

```
node test.mjs
```

假 Worker（node 小脚本，命令行和 video_run.py 一样）+ 假的 ctx：校验参数（图的文件夹、排序、工程怎么挑、版本号怎么定）→ 成功、失败、点停止 → 拦写 → 上下文 → 字幕样式 → 改名重试（真占着一个文件）→ 没写总结就退出。
10-01 故意改坏三处验证测试会响：失败时不改名 → 3 项没过；不拦剪映草稿文件夹 → 2 项没过；吸格线前的备份也算成工程 → 7 项没过。
