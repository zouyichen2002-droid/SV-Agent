# 做歌词视频

1. **先确认在这首歌的项目里**：上下文里有「SV 项目：《…》」，而且这首已经翻唱过（字幕的时间从 SV 工程来）。
   在大厅里：请创作者到侧栏那首歌下面开新会话、把要求再说一次。
2. **要两样东西**，缺哪样就用 ask_user_question 问清楚再调：
   - 成品音频：创作者混好的整首（wav / mp3 / flac…）的**绝对路径**
   - 画面：图或视频（「底片」，会循环铺满）的绝对路径，一个或几个，或者放它们的文件夹（按文件名排；几个就整首平均分、交叉淡化）。
     **只用创作者给的画面**，不要自己找图、做图
   - 可选：标题（不说就是《歌名》）、署名（标题下面那行小字；创作者没说就不放，不要自己编）、
     用哪个工程（不说 = 这首 rNN 里最近改过的那份 `.svp`；创作者说「用 r02 的」就填 `r02`，给了路径就填路径）、
     字放哪边 `side`（不说 = 自动看画面哪边空；创作者说「字放右边」就填 `right`）、
     字幕样式 `fx`（不说 = **可爱**：快乐体、白字彩色描边带光、一句拆成几行错落或斜台阶，像 B 站《樱草哀歌》那种 —— 创作者 10-02 定的默认）；
     别的：凌厉（毛笔楷书大字一下砸进来、旁边竖排小字红白相间、红色刀痕、画面压暗 —— 创作者说「凌厉」「狠一点」「燃」时用）、
     平铺（原来的整行逐字变色）、弹跳、发光、浮现、逐字出现、竖排古风（华文行楷竖排，给中文 / 日语的古风歌）——
     **创作者点名了才填**，不要自己挑；可爱、凌厉在剪映草稿里也照着配（字体、颜色、出场方式），别的样式剪映里还是剪映自己的卡拉OK
3. **调 video_run**（audio、images、可选 title、credit、svp、side、fx）。它马上返回，在后台做约 3–5 分钟；不用让出大模型。
   调完用一两句话告诉创作者：已经开始、大概多久 —— **然后结束这一轮**。不要调 job_output 等它。
4. **做完你会被唤醒**，任务结果里有成片路径、剪映草稿名、对齐结果、要提醒的：
   - 成功：用 present 交付成片（`.mp4`）和同一版的 `说明.md`；两三句话说：草稿在剪映的草稿列表里叫什么、字幕时间从哪个工程来、
     成品音频和工程差了多少（结果里怎么写就怎么说）。**结果里有「要提醒创作者」就原样告诉他**（比如音频和工程对不上、中间剪过段落）。
     最后告诉创作者：想改字体、配色、动效，直接在剪映里改那份草稿；要换图、换音频、字幕不对，跟你说一声，会另出一版
   - 失败：把任务结果里那句原样告诉创作者（哪一步、日志在哪；「中途退出、没写总结」就是被结束了或崩了），问要不要再做一次。
     **不要去翻日志文件、读脚本、查代码找原因**（10-01 试的时候翻了 4 个日志、上下文用到 73% 还在找）—— 修是开发那边的事
5. **别做**：别用 pwsh 自己跑视频脚本；别改做好的 `视频\vNN\`（要改就再调一次，会另开一版）；
   别去剪映的草稿文件夹里动任何东西（草稿只许 video_run 新建；创作者要改字体、动效就在剪映里改）；别把歌词贴回对话里。
