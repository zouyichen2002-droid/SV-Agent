# 决策记录（ADR）

每条 ADR 记一个非平凡的技术岔路：**背景 → 选项 → 选了什么 → 证据 → 什么证据会推翻它**。

## 为什么写这个

这个仓库的代码由 agent 写，决策由人做。ADR 是后者的载体，也是这个项目最主要的产出：
它记的是"为什么选 X 不选 Y"和"错的时候是怎么发现的"，而不是"最后跑通了什么"。

## 编号与命名

- 本仓库的 ADR 从 `0001` 起，文件名 `NNNN-<kebab-case-标题>.md`。
- **上游 `synthv-agent-bridge` 有自己的一套 ADR 0001–0008**（`E:\SV_MCP\docs\adr\`）。
  两套编号会撞。**引用上游的一律写成 `upstream ADR-000N`**，例：
  `upstream ADR-0001（SynthV 是唯一权威）`。本仓库的直接写 `ADR-0001`。
- 语言：ADR 用中文（工程日志，精度优先）。仓库 `README.md` 是对外的，用英文。

## 状态取值

`提议中` · `已接受` · `已被取代（→ ADR-NNNN）` · `已推翻（证据：…）`

被推翻的 ADR **不删除**，改状态并补一行推翻它的证据。推翻的记录和成立的记录同等重要。
