# M1-01 探针：人声扒谱准不准（翻唱 MVP · C03）

**探针 = 只为回答一个可行性问题而写的一次性代码，不进产品。**
问题：SynthV 自带的 Voice-to-MIDI（右键音频 →「Extract Notes from Audio」）扒 Suno 的人声分轨，离你改完的终稿有多远？

标准答案：《傍晚》04-17 终稿的主唱轨（你改完的版本，PRD §6.5 批准的第一首逆向学习曲）。
输入：Suno 分出来的 `0 Lead Vocals.wav`。扒谱这一步只能在 SynthV 界面里点（脚本接口做不了，M0-04）。

| 口径 | 值 |
|---|---|
| 扒对一个音 | 起音相差 ≤ 50 ms，且音高相差 ≤ 50 音分 |
| 另外报 | 只看起音的 F1、起音对上里音高也对的比例、八度错误、时值比、歌词 |
| 整体偏移 | 音频放的位置差一点也不怕：先在 ±2 秒内找整体偏移（最长平台的中点 + 残差细调） |

自检：自己比自己 100%；整体移八度全算八度错；删 20% 召回 80%；整体挪 0.3 秒能找回；加 20% 乱音精确率会掉。不过就不比。

```bash
cd /e/sv-bridge/spikes/m1-01-voice-to-midi && python compare_notes.py <标准答案.svp> <被比的.svp> [<答案里的轨名>]
```

- 输入只读；报告写在仓库外 `E:\sv-agent-data\learn\01-傍晚\`（曲目数据不进公开仓库）
- 基线：你自己的 04-12 第一版对 04-17 终稿，F1 0.875（你前后改了约 12% 的音）
