# M1-02 探针：和声识别（翻唱 MVP · C04）

**探针 = 只为回答一个可行性问题而写的一次性代码，不进产品。**
问题：Suno 的人声分轨里有没有和声、能不能扒出来？标准答案：《傍晚》04-17 终稿的「和声1」。

## 第一步结论（09-29）：这首的「和声」是八度叠唱

- 终稿「和声1」一共 30 个音，全在 1:56–2:14，**每个都正好比主唱高一个八度**，起音和主唱完全对齐
- 人声分轨里，**Suno 在两处上下两个八度一起唱**：1:27–1:32、1:57–2:01；2:01–2:14 只唱了上八度
- 所以 M1-01 那 23 个「八度错」都不是扒错：GAME 两个八度一起唱时挑一个，跟录音走；
  和终稿对不上，是创作者编曲时选了另一个八度（1:27–1:32 留上八度；1:56–2:14 主唱放下八度、上八度做和声）
- **更正（09-29 做 r02 时）**：第一步说「2:01 之后的下八度是创作者自己加的」—— 不一定。2:05–2:09 basic-pitch 同时报了下八度，
  频谱读数（−7 到 −25 dB）也比只有一个声部时（约 −32 dB）高 —— Suno 那里很可能有一条**比较轻的**下八度，终稿的主唱跟的就是它
- 把终稿 1:56–2:14 换成「和声1」（Suno 唱的那个八度）再比，r01 的 F1 从 0.573 升到 0.607

**对和声识别的意思**：Suno 真唱了两个声部的地方能识别（两个八度都扒出来，拆成两条轨，哪条当主唱由创作者定 ——
这首两处选法不一样，不能替他定死）；Suno 只唱一个声部的地方，和声是创作者的创作，扒不出来，也不该凭空编（R03）。

## 怎么判「下面有没有一个八度」（`octave_double.py`）

设上面那个音的基频为 f：只有它一个声音，能量只在 f 的整数倍；下面再有一个八度（f/2），还会在 **f/2、1.5f、2.5f**
（f/2 的奇数倍）上有能量 —— 上面的声音自己产生不了。看这些能量比 f 的整数倍低多少 dB。

| 看哪里 | 读数（中位） |
|---|---|
| 自检：合成一个声部 / 两个声部 | −66 dB / −7 dB（完全分得开） |
| 对照：只有主唱的段落，看主唱下面有没有八度 | −32 dB |
| 1:56–2:14（和声1 那 30 个音） | −15 dB；1:57–2:01 那 9 个在 −11 到 +6 dB |

新旧两条人声分轨结论一样。**第一版的对照写反了**（假设主唱上面还有八度，「下面」正好是主唱本人，读数当然高），已改。

```bash
python octave_double.py <人声分轨.wav> <终稿.svp>
```

## r02：把另一个八度扒出来，放成「叠唱」轨（`make_r02.py`）

GAME 挑了低八度的地方，上面那个八度被低八度盖住（泛音全落在低八度的偶数倍上），上面的频谱判法看不出来 → 前后三稿：

| 稿 | 判法 | 结果 |
|---|---|---|
| 1 | 频谱「上面有没有八度」（偶数倍比奇数倍高多少），分界线用整首歌自己算 | 线算到 +12 dB，已知的一个没抓到、方向还放反；**没交** |
| 2 | **basic-pitch（能同时扒出好几个音）同时报了 p±12**、覆盖一半以上、强弱比 ≥ 0.4，连着 ≥ 3 个 | 已知叠唱的 19 个音里 13 个报了、强弱比中位 1.03；只有一个声部的 88 个里 **0 个**。但 41 个里 25 个放到下面，有的比整首最低音还低（A2、B2）；**没交**，挪进 `rounds\r02_弃用_方向放错` |
| **3（交的 r02）** | 同 2；**往下放另要两个条件**：频谱旁证（读数 > 整首中位 + 12 dB）、不低于音域下限 − 2 个半音 | 39 个（上 19、下 20）；两条轨合起来对终稿「主唱 + 和声1」**0.675**（r01 是 0.618）；1:57–2:01 那句和「和声1」对上 |

在终稿没做八度处理的地方多报了一句：**1:12–1:16**（7 个音）—— M1-01 的 pyin 在 1:12–1:34 也读低了八度，很可能 Suno 那里也叠了，要创作者听。

分界线（强弱比、覆盖、频谱门槛、音域）都是在《傍晚》上定的 —— **换一首歌要重新验**，不能当定论。
