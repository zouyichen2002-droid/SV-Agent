- 和终稿还差的 5 个，就是**你给的歌词和终稿本来不一样**的地方（你的歌词 185 字，终稿 189 字：5 处用字不同、1 处多了 4 个拖音）

## 规则（`repair_lyrics.py`）

1. 对上的音 → 换成歌词里那个字的拼音（终稿用的就是拼音）
2. 有字没地方放、附近有够长的空位 → 放进空位；空位旁边没多余的字 → 留「-」当拖音
3. 真没空位（**字比音多，就是漂移**）→ 把前一个音对半拆开，后一半给这个字（前一个太短就拆后一个）—— 每一处都列出来
4. 多出来的音（歌词里没有这个字）→ 改成「-」
5. Suno 唱得和歌词明显不一样的地方照你的歌词放，但列出来（修歌词时动过的地方不报：那里只靠听写的对齐本来就乱）

对齐（`lyric_align.py`）：按拼音做全局对齐；拼音一样 +3，近似（前后鼻音、平翘舌、n/l）+1，不一样 −1，一边空着 −2；
空位放字 +1（太短的碎音 −1），空位一直空着 0。

**自检**（不过就不用；例子都是造的，不含你的歌词 —— 仓库是公开的）：
- `clean_lyrics.py`：标题、段落标签（主歌 / 副歌 / [Chorus] / Verse 1 …）、破折号去掉
- `lyric_align.py`：一样 / 少一个 / 多一个 / 近似 / 中间连少 5 个 / 空位三种（真实遇到过的两种形状 + 真拖音不能被填）
- `repair_lyrics.py`：造一段歌词当音，注入空位、近似音、删一个音（考拆音）、多一个音 → 修完必须和原文一字不差
