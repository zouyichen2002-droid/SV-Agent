# M2-00 探针：最小生成

**探针 = 只为回答一个可行性问题而写的一次性代码，不进产品。**
这里的问题是：Medium 3.5 写的旋律你愿不愿意继续做？约束词有没有用？
结论见 [`docs/m2/00-gen-probe.md`](../../docs/m2/00-gen-probe.md)。

| 文件 | 做什么 |
|---|---|
| `probe.py` | 提示词、并行调 Mistral、预算闸、没过硬检查就改一次（还不过就从头再来一次）、盲听编号、写试听单和揭晓 |
| `check.py` | 硬检查 + 建议性的数 + 约束词执行情况；**自带 9 种注入缺陷的自检**，不过就不跑 |
| `music.py` | 和弦解析与配和声、拍 → 秒、渲染钢琴试听、写 `.svp`。渲染器用 M0-01 的，`.svp` 模板和声库用 M0-04 的 |

```bash
cd /e/sv-bridge/spikes/m2-00-gen-probe && python probe.py
```

- 需要仓库根目录的 `.env` 里有 `MISTRAL_API_KEY`（被 git 忽略；程序不打印它）
- 一次约 ¥1（4 段），产物在 `out/run_<时间>/`，**不进仓库**
- 有段没过硬检查：`python probe.py --fill run_<时间>` 只补那几段，盲听编号不变
- 运行前 SynthV 里别开着要被重写的 `.svp` —— 每次运行都写新目录，不会覆盖旧的
