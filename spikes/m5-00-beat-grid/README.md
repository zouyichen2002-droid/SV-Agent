# M5-00 探针：找一首歌的真实拍子（逆向学习第一步）

**探针 = 只为回答一个可行性问题而写的一次性代码，不进产品。**
PRD 里逆向学习是 V2（M5）；创作者 09-28 定了先做，《傍晚》是第一首（PRD §6.5）。

问题：工程里的速度不一定是歌真实的拍子（《傍晚》的工程是 120，音却不在 120 的网格上）。拍子不准，学出来的节奏型全是错的。

| 裁判 | 做法 |
|---|---|
| ① SynthV 自己的节拍分析 | 读 `.svp` 伴奏轨 `audio` 里的 bpm、alternativeBPMs、beatLocations |
| ② librosa | 对同一段伴奏重新做节拍跟踪 |
| ③ 人声起点 | 按候选速度的网格、以及按 ①② 的拍点序列**局部**量（容得下速度漂移），每项都和**随机撒点的偶然水平**比 |

自检：已知 132 BPM 的合成起音必须测对、用错的速度和随机数据不许「对齐」、librosa 必须测得出 132 BPM 的点击声。不过就不跑。

```bash
cd /e/sv-bridge/spikes/m5-00-beat-grid && python beat_grid.py "<svp 路径>" <编号-曲名>
```

- 输入只读（云端同步目录一个字节都不写）
- **结果写在仓库外**：`E:\sv-agent-data\learn\<编号-曲名>\` —— 曲目数据不进公开仓库
